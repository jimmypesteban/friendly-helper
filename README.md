# Friendly Helper

A small social-emotional learning game for kids aged 5–8, set in Hong Kong. A short scene plays, the child picks one of four actions, and gets gentle feedback. Getting it right earns a Friendly Helper badge.

**Live:** https://friendly-helper.vercel.app

Every play gets a new situation, four choices and feedback, all generated by an LLM (Gemini) on the server. The original version was a single hand-written scenario, which is kept as the fallback when the API is unavailable.

## How it works

- `api/scenario.js`: Vercel serverless function. The API key stays on the server.
- `lib/scenario.js`: prompt, JSON output schema, validator and repair loop. The schema has one `helpful` slot and three named wrong-answer slots (`ignore`, `careless`, `in_the_way`), so "exactly one correct answer" is guaranteed by structure. The server shuffles the choices.
- `lib/settings.js`, `lib/scenes.js`: the Hong Kong settings, and what is visible in each background clip.
- `clips/`: pre-generated background clips (Veo), one per setting. `scripts/make-clips.mjs` builds them.
- `scripts/eval.mjs`: test harness. Runs many generations, validates them, and grades them with a second model (one clear answer, age-appropriate, safety, shaming, match to the video frame).

[PROMPT_NOTES.md](PROMPT_NOTES.md) covers the prompt design, test results across versions, and what broke along the way.

## Run locally

```bash
npm install
echo "GEMINI_API_KEY=your-key" > .env.local
npm run dev            # http://localhost:3030
node --env-file=.env.local scripts/eval.mjs   # costs API credits
```
